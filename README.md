# 🏋️‍♂️ SmartGym – Bezoekers Registratie & Live Dashboard

SmartGym is een systeem om het aantal bezoekers in de sportschool bij te houden.
Met RFID (later in Sprint 2/3) wordt automatisch geregistreerd wanneer iemand binnenkomt of weggaat.

Het dashboard toont live het aantal aanwezige bezoekers en geeft waarschuwingen bij een hoge bezetting.
Ook wordt een grafiek en AI-voorspelling getoond.

---

## 🚀 Functionaliteiten (Sprint 1 + 2)

- ✔ Live aantal bezoekers
- ✔ Bijna-vol waarschuwing (rood)
- ✔ Grafiek drukte per uur (matplotlib)
- ✔ AI voorspelling bezoekers over 1 uur
- ✔ SDG-duurzaamheidsuitleg

📌 JSON wordt tijdelijk gebruikt als database-opslag.
